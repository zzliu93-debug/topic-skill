# 输出规范

## AI 简报

文件：`AI资讯/日报/YYYY-MM-DD-AI简报.md`

覆盖北京时间昨日 00:00 至执行时刻。必须全量覆盖该窗口获取到的 AIHOT `selected` 条目：相同事件可合并为一个事件簇，但每条精选提供的不同事实都要写入对应事件簇。将这些事件簇与 `last30days` 的近期讨论合并去重；讨论充分且事实可验证的 `last30days` 独有事件也纳入简报。

所有事件簇按“引发读者评论或讨论的可能性”从高到低连续编号，不按日期或来源分组。正文不写来源、平台名、原始链接、时间戳、互动数据、评分或“编辑判断”等标签。

每个事件固定使用以下形式：

```markdown
## N. 事件标题

**发生了什么事：** 用完整的事实叙述交代主体、动作、进展和必要背景；同一事件合并了多条精选时，分别写清各自新增的事实。

**值得关注什么：** 直接说明它为何更可能引发讨论：影响谁、改变什么、存在哪些争议、不确定性或实际利益。
```

来源链接与逐条映射仅保留在本次工作流的临时研究记录中，不写入日报。
